MISSION I:
Les résultats des matchs de football des différentes catégories d’âge (U11, U13, U15…) sont dispersés sur plusieurs sites. Pour suivre une équipe ou une catégorie, il faut aller chercher l’information à plusieurs endroits.Je souhaite développer une application où les clubs saisissent les scores à la fin des matchs et où tout le monde peut consulter les résultats au même endroit.

Utilisateurs

Gestionnaire de club (celui qui saisit) — il doit pouvoir : - ajouter un club et ses équipes ; - saisir le résultat d’un match ; - modifier un score ; - signaler l’annulation d’un match ; - modifier la ligue d’une équipe.

Visiteur (celui qui consulte) — il doit pouvoir : - consulter les résultats ; - rechercher une équipe ; - rechercher / filtrer par catégorie

Mon application permet aux clubs et aux supporters de saisir et consulter les résultats de matchs de football de toutes les catégories d’âge afin de ne plus avoir à aller sur différents sites pour voir un résultat.

MISSION II:

L’utilisateur doit pouvoir consulter les résultats des matchs.
L’utilisateur doit pouvoir ajouter un club.
L’utilisateur doit pouvoir ajouter une équipe.
L’utilisateur doit pouvoir saisir le résultat d’un match.
L’utilisateur doit pouvoir modifier le score d’un match.
L’utilisateur doit pouvoir modifier la ligue d’une équipe.
L’utilisateur doit pouvoir marquer un match comme annulé.
L’utilisateur doit pouvoir rechercher une équipe par son nom.
L’utilisateur doit pouvoir filtrer les résultats par catégorie.

Équipe : un club dans une catégorie donnée (ex. « AS Dumbéa U13 »).
Catégorie : la tranche d’âge (U11, U13, U15…).
Ligue : l’organisation à laquelle l’équipe est rattachée.
Match annulé : le match reste enregistré avec le statut « annulé » ; il n’est pas supprimé.
