# Architecture technique

## Frontend

Technologie : HTML / CSS / JavaScript

simple à apprendre et à expliquer, suffisant pour afficher des listes, des formulaires et une recherche.

## Backend

Technologie : PHP (API REST)

 langage vu en cours, facile à utiliser avec une base de données.

## Base de données

PostgreSQL
adaptée à mon MLD (tables reliées par des clés étrangères).

## Communication frontend/backend

Méthode : API REST, échanges en HTTP / JSON.
